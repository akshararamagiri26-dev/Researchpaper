# KCIR Decision Support

Uploaded project archive for the knowledge-guided decision-support study.

## Files
- `kbs_dss.py` — core experiment and decision-support implementation.
- `manuscript.md` — manuscript draft.
- `manuscript.docx` — editable Word manuscript.
- `results.json` and `results_scenarios.csv` — recorded experiment outputs.
- `fig1_case.png` and `fig2_benchmark.png` — experiment figures.
- `highlights.txt` — paper highlights.
- `requirements.txt` — Python dependencies.

## Scope note
Please inspect the manuscript and experiment before publication. Synthetic benchmark results should be described as pipeline demonstrations rather than evidence of effectiveness in real organizations.
